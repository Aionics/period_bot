# Period.

Telegram-бот для себя и подруг: отмечает месячные, считает овуляцию и окно, когда можно забеременеть, присылает напоминания и подсказку дня.

## Приватность

- Каждая девушка видит только свой календарь. Общих списков нет, «режима админа» с доступом к календарям нет.
- Имя, ник и фото не сохраняются. В базе лежит только номер чата Telegram (без него бот не сможет написать) и один **зашифрованный** блок с датами и настройками.
- Ключ шифрования `CRYPT_KEY` лежит в `.env` на сервере. Человек с доступом к серверу технически может расшифровать базу, но для этого нужно делать это специально. Девушкам бот говорит об этом честно (кнопка «Подробнее» на экране приватности).
- Содержимое сообщений в лог не пишется. Резервных копий нет, поэтому после `/delete` данных не остаётся. Удалённые записи затираются в файле базы (`secure_delete`).
- Создательница бота видит только одно: командой `/count` — сколько всего человек пользуется ботом.
- Бот открыт: зайти может любой, кто знает его имя, но каждая видит только свои данные. Если понадобится закрыть вход, впиши в `.env` строку `INVITE_CODE=<код>`: тогда бот будет пускать только по ссылке `t.me/<бот>?start=<код>`.

## Что умеет

**Анкета при первом входе** (около минуты):
экран приватности → день начала последних месячных (календарь) → сколько длятся месячные (кнопки) → длина цикла (вписать число или «Не знаю») → режим → время уведомлений → часовой пояс.

**Режимы:**
📅 Просто слежу · 👶 Хочу забеременеть · 🛡 Не хочу беременеть · ⏸ Пауза (бот молчит).

**Каждый день в выбранное время:**
- подсказка дня по фазе цикла (тексты в `texts.py`) и кнопки самочувствия 😊 😐 😔 😤 🤕 😴;
- за 2 дня до месячных: «Положи прокладки в сумку»;
- в день прогноза: «Месячные начались?» → `Да, сегодня` / `Да, раньше` / `Ещё нет`. При «Ещё нет» бот спросит снова завтра, а на 7-й день задержки мягко посоветует тест или врача;
- пока идут месячные: «Ещё идут?» → слабо / средне / сильно / закончились;
- в режимах «Хочу» и «Не хочу беременеть»: за 2 дня до окна, в первый день окна и в день овуляции.

**Календарь** (`/calendar`): 🔴 месячные · ⭕ прогноз · 🟡 можно забеременеть · 🥚 овуляция · 📍 сегодня. Нажатие на день — отметить или снять месячные, указать обильность, отметить овуляцию по тесту.

**Статистика** (`/stats`): средний цикл и месячные, последние циклы, разброс, длина второй фазы. Предупреждает, если цикл вне 21–35 дней, сильно скачет или месячные дольше 7 дней. Через 2–3 цикла показывает личные закономерности по самочувствию.

**Тихий режим**: в уведомлениях нейтральные слова («Гости пришли?»), чтобы на экране блокировки ничего не было понятно.

## Как считаются прогнозы

| Что | Как |
|---|---|
| Длина цикла | Среднее по последним 6 реальным циклам. Пока их нет — из анкеты (или 28) |
| Длина месячных | Среднее по отмеченным дням, пока их нет — из анкеты |
| Следующие месячные | Начало последних + средний цикл |
| Овуляция | Следующие месячные − длина второй фазы. Стандарт — 14 дней. Если отмечать овуляцию по тестам, бот считает личную длину |
| Окно, когда можно забеременеть | От 5 дней до овуляции до 1 дня после |

Основа: [Bull et al., 2019](https://pubmed.ncbi.nlm.nih.gov/31482137/) (612 тыс. циклов: средний цикл 29,3 дня, вторая фаза 7–17 дней) и [Wilcox et al., 2000](https://www.bmj.com/lookup/volpage/321/1259) (окно — 6 дней, заканчивающихся овуляцией; календарный метод ненадёжен).

## Запуск на компьютере

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`):
   - имя: `Period.`
   - username (должен заканчиваться на `bot`): `period_dot_bot`, если занят — `periodtochka_bot` или `period_svoi_bot`.

   Скопируй токен. Описание бота и список команд он выставит себе сам при запуске.
2. Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN`.
3. Создай ключ шифрования и впиши его в `CRYPT_KEY`:
   ```
   .venv\Scripts\python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```
4. `INVITE_CODE` оставь пустым — бот будет открыт для всех.
5. Поставь окружение и запусти:
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
   Затем дважды кликни `run.bat`.

## Запуск на сервере через Docker

> ⚠️ Бот должен работать только в одном месте. Перед запуском на сервере останови его на компьютере.

```
git clone <адрес репозитория> ~/period-bot
cd ~/period-bot && bash install.sh
```

При первом запуске скрипт спросит токен, сам создаст ключ шифрования, сохранит всё в `.env` с правами `600` и покажет ссылку на бота.

> ⚠️ **Сохрани копию `.env` в надёжном месте.** Если потерять `CRYPT_KEY`, данные девушек расшифровать будет нельзя.

**Обновление после правок в коде:** `cd ~/period-bot && bash install.sh`

| Что | Команда |
|---|---|
| Посмотреть лог | `docker compose logs -f` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |

## ⚠️ Важно

Бот — напоминалка, а не медицинский прибор и не контрацепция. Овуляция может сдвигаться даже при регулярном цикле.
